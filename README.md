Agent Traffic Lab provides a routing platform that connects AI agents to supported tasks such as search, extraction, summarization, translation, and classification. It evaluates provider eligibility, applies policy and budget constraints, and executes tasks with bounded fallback, delivering durable outcomes and performance metrics.

**Areas:** AI · Routing · Automation · Agents · Platform · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Agent Traffic Lab: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
